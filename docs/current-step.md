## Проверяемая реализация

Программа читает `MAPS/*.MAP`, `TERRAIN/*.MCD`, `GEODATA/LOFTEMPS.DAT` из локального каталога игры. MAP имеет три ненулевых байта размеров и четыре байта на ячейку. Допустимая длина — `3 + 4×d₀×d₁×d₂`. MCD содержит положительное целое число записей по 62 байта, LOFTEMPS — положительное целое число 32-байтовых блоков.

Отчёт — JSON `fgm-regenerator/inspection-v1` в UTF-8. По умолчанию результат пишется в стандартный вывод. Параметр `--report` создаёт новый файл в существующем каталоге за пределами источника игры и отклоняет занятое имя. Отчёт содержит имена поддерживаемых ресурсов, размеры и диагностику без абсолютных путей и содержимого игровых файлов.

Проверка ограничена 16 МиБ на файл и 10 000 записями в каждом просмотренном каталоге с учётом пропускаемых записей. Имена форматов сопоставляются без учёта регистра ASCII. Неоднозначные имена обязательных каталогов и `LOFTEMPS.DAT` считаются ошибкой структуры. Пути к источнику и каталогу отчёта разрешаются без перехода по символическим ссылкам. В Windows поддерживаются пути с буквой диска, точки повторной обработки отклоняются.

**Важно:** размерные проверки ещё не подтверждают смысл полей и не гарантируют согласованности карт, маршрутов и вокселей.

## Правила завершения задачи и передачи контекста

Каждый PR обязан содержать проверяемые дочерние Requirements с отношениями `derives_from`, `implemented_by` и `verified_by` для реализованных свойств. Тесты используют собственные синтетические данные. `FGMR-PROC-001` и `FGMR-IMPORT-001` имеют статус кандидатов до явного авторского принятия.

Для продолжения в новом чате читать в порядке: этот документ → [R12 #17](https://github.com/netkeep80/fgm-regenerator/issues/17) → [эпик R00 #4](https://github.com/netkeep80/fgm-regenerator/issues/4) → `requirements/` → текущий Draft PR и его exact SHA.

Перед закрытием среза в Issue фиксируются **BASE, HEAD, TREE, CI, тесты, статус принятия, merge-коммит и следующий один шаг**. `main` не изменять напрямую. Merge без явного авторского принятия запрещён.

Документация на русском языке; исходные игровые данные и производные ресурсы не размещаются в публичных репозиториях.
